# MetaOpticsAI

MetaOpticsAI is an AI-assisted platform for automated meta-optics design and electromagnetic simulation.

It integrates RCWA-based unit-cell simulation using the MetaBox engine with phase-profile generation and optical analysis.

The pipeline supports metalens design, parameter sweeps, PSF/MTF analysis, optimization, and GDSII fabrication-layout generation where implemented.

An optional LLM orchestration layer enables natural-language interaction with the scientific workflow.

Built with Python, TensorFlow, NumPy, and modular scientific-computing components.

Developed for research, experimentation, and future extensions in computational photonics and metasurface engineering.

**Acknowledgment:** The RCWA engine is based on [MetaBox](https://github.com/luochenghuang/metabox); see the applicable license and attribution notices.
